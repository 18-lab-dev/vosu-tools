ESources & settings

Downloads use a source whose operator allows automation. No silent failover. Each source is paced at 2 seconds per request or slower; 429/Retry-After and transient-server backoff apply. osu.direct terms · API and budgets

Sources, credentials & saved workspace

Credentials stay in private service settings on disk (not an encrypted keychain). No browser storage is used. Official metadata requests are cached for 10 minutes and paced at ≤1 request/second. Official OAuth download endpoints are not used.

Custom sources must implement the documented osu.direct API shape. Set enabled, priority (lower first), interval_ms (≥2000), terms_url, and automation_permitted only after checking operator terms. Disabled sources receive no new traffic; queued jobs retain their explicitly chosen source.
